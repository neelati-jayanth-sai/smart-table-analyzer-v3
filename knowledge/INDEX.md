# Knowledge map

Curated reference notes for investigating Apache Iceberg tables on IOMETE with Spark.

- `iceberg/`: snapshots, files, manifests, partitions, delete files, and maintenance.
- `iomete/`: platform behavior, Spark/Iceberg writes, maintenance behavior, and property precedence.
- `runbooks/`: team standards — file sizing, partition design, sort orders, maintenance conventions.
- `spark/`: Iceberg SQL metadata surfaces and read-only inspection considerations.
- `diagnostics/`: competing explanations and evidence considerations for common symptoms.

Use search to locate a note, then read only the relevant bounded range. These notes describe general behavior and team standards; observations about a target table come from deterministic measurement tools and stored results (Rxxx). Knowledge is context, not evidence.
